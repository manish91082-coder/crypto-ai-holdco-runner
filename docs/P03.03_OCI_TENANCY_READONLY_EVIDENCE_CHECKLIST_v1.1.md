## 1. Existing account / subscription

If an OCI account already exists, sign in at https://cloud.oracle.com. Record only subscription category: Free-Trial, Always-Free-only or Pay-As-You-Go. Do not sign up, upgrade, add payment method or change billing settings.

## 2. Home Region

Profile menu → `Tenancy: <tenancy-name>` → Tenancy Details. Capture only Home Region label. Redact tenancy name/OCID and personal information.

## 3. A1 Compute limits

Navigation → Governance & Administration → Tenancy Management → Limits, Quotas and Usage. Select Compute and Home Region where available. Capture A1 OCPU and memory Service Limit / Usage / Available. A missing row means UNKNOWN, not zero.

## 4. HSM key-version limits

On Limits, Quotas and Usage select Key Management. Capture HSM-protected key-version Service Limit / Usage / Available. Do not create a Vault, Secret or key.

## 5. Existing VCN and IPv6 state (added in v1.1)

Only inspect existing resources. Do not create a VCN, add IPv6 or modify routes.

1. Navigation → Networking → Virtual Cloud Networks.
2. If a VCN already exists, inspect CIDR Blocks/Prefixes or IP Administration.
3. Record whether it has Oracle-assigned IPv6 GUA /56, BYOIPv6, ULA, or no IPv6 prefix.
4. Inspect existing subnet details. Record Public/Private and whether an IPv6 /64 is assigned.
5. Inspect existing Gateways: Internet Gateway, NAT Gateway, Service Gateway.
6. Inspect existing route table summaries. Record whether default IPv6 route `::/0` points to Internet Gateway.
7. Inspect existing NSG/security-list rules. Record whether IPv6 ingress permits SSH TCP/22 from `::/0`, and whether IPv6 egress is unrestricted.

Redact names, CIDRs, addresses, OCIDs and private infrastructure details. Share only high-level states.

## 6. Neon Data API IPv6 boundary

The canonical Neon main branch currently has Data API disabled; there is no active branch-specific Data API URL to inspect. Do not enable Data API on main.

Only after a separate disposable Neon child branch and Data API activation are explicitly authorised:
- Read the exact branch-specific Data API URL returned by Neon's API.
- Record its public hostname only; do not share tokens.

Neon AWS PostgreSQL IPv6 support does not prove Data API HTTPS IPv6. They are separate gates.

## 8. Provider facts and decision boundaries

- OCI Always Free A1 must be in Home Region; 1,500 OCPU-hours and 9,000 GB-hours/month (2 OCPUs / 12 GB).
- Free Tier tenancies without paid status/Free Trial credits may have up to two VCNs.
- OCI supports Oracle GUA /56, public-subnet /64 and Internet Gateway IPv6 routing.
- OCI default IPv6 security-list examples can permit SSH TCP/22 from `::/0`; any test must explicitly deny inbound management.
- Neon AWS PostgreSQL endpoints support IPv6; Data API hostname AAAA/IPv6 HTTPS remains unknown until a branch-specific test.
- First 10 TB/month APAC-origin outbound data transfer is published free; overage may be billed.
- Exact account-specific charge treatment of Oracle GUA/Internet Gateway, plus no-overage controls, is not proven. Unknown billing is NO-GO.
- A1 idle-reclamation risk remains.

## 9. Decision rules

| Gate | PASS evidence | NO-GO |
|---|---|---|
| Existing tenancy/subscription/Home Region | Read-only account evidence | No new signup in this gate |
| A1/HSM/VCN quotas | Remaining Always Free allocations verified | Only paid resource/upgrade |
| IPv6 GUA + IGW | Existing/eligible GUA and public route documented | Requires unknown/billable resource |
| Neon Data API | Exact branch URL has AAAA and IPv6 TLS/HTTPS works | No AAAA or TLS failure |
| Egress control | Stable endpoint addresses allowlistable | Unbounded/rotating set or egress bypass |
| Billing | Exact GUA/IGW and outbound cost/no-overage proven | Any unknown or billable component |
| Security | No public ingress; SSH from ::/0 removed; exact egress allowlist | Uncontrolled management or outbound traffic |

PASS only allows proposing a separately authorised sandbox test. It does not authorise resource creation, Data API activation, key generation, Functions, triggers, source activation or production work.
